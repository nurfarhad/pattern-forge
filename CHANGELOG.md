# Changelog

## 1.0.0 — 2026-11-14

First public release.

- Four source modes: Random, Fill Selection, Anchor Around Selection, Batch Selection
- Colour blocks from an 11-colour brand palette, with per-swatch overrides
- Multiply, Screen, Darken and Normal blend modes
- Signature gradient block and vector halftone texture
- Serif data-readout labels with a font picker
- Output sizes: Square 1:1, Widescreen 16:9, Portrait 9:16, Social OG 1.9:1, or custom
- Three built-in presets plus your own saved presets
- Live editing: select a forged frame and every change updates it in place
- Seeded and repeatable: the same seed and settings always give the same pattern
- No network access
