# Pattern Forge — Architectural & Contract Decisions

This document records the definitive decisions on the shared data contract (`src/generator/scene-spec.ts`) and renderer behavior across the plugin UI iframe, generator core, and Figma main thread.

---

## 1. Shared Data Contract (`scene-spec.ts`)

The data contract is shared across both renderers: the **live canvas preview** in the UI and the **native node renderer** in the Figma sandbox. It extends the PRD Section 9 sketch to satisfy the functional requirements and Figma API constraints:

| Type | Field | Type | Rationale |
|---|---|---|---|
| `TextureSpec` | `opacity` | `number` (0–1) | Halftone dot grids require semi-transparency (0.08–0.22) so they act as ambient texture rather than solid foreground. Figma's `set_opacity` API strictly validates that `node.opacity` is a finite number and crashes if `undefined`. Canvas preview uses it for visual parity. |
| `LabelSpec` | `opacity` | `number` (0–1) | Data-readout labels require controlled opacity (e.g. 0.85). Preview and Figma renderers both apply this value. |
| `BlockSpec` | `gradient` | `GradientSpec?` | Optional field so block processing functions can handle solid blocks and gradient blocks uniformly. |
| `SceneSpec` | `gradientBlock` | `(BlockSpec & { gradient: GradientSpec })?` | Explicit top-level slot for the procedural gradient block (PRD §9.1), rendered into the `Blocks` group with a `GRADIENT_LINEAR` fill in Figma and linear gradient on canvas. |
| `GenerationParams` | `displayFont` | `string` | PRD §10 explicitly requires a font selector in the Labels panel (defaulting to `"Times New Roman"`). Preloaded on the main thread via `preloadSceneFonts()` before creating `TextNode`s. |
| `GenerationParams` | `blendModes` | `BlendMode[]` | Active blend modes in rotation (e.g., `['MULTIPLY']` or `['NORMAL', 'MULTIPLY']`). Generator randomly selects from this set for cluster blocks. |

---

## 2. Defensive Figma API Guards

Figma's C++ binding layer validates all node properties strictly. Unlike HTML `<canvas>`, which silently coerces or ignores `undefined`/`NaN`, Figma throws uncaught exceptions:

1. **`safeOpacity(v, fallback = 1)`**: Every `.opacity` assignment on `RectangleNode`, `TextNode`, and vector/SVG nodes passes through `safeOpacity()`, ensuring the value is finite and clamped to `[0, 1]`.
2. **Dimension guards**: `Math.max(1, width)` and `Math.max(1, height)` are applied on frame, block, texture, and text resizing.
3. **Empty group guards**: Groups (`figma.group()`) are only instantiated when the child array is non-empty (`length > 0`).

---

## 3. Preview vs. Figma Parity Invariant

The same deterministic `SceneSpec` generated by `generateScene(params, constraints)` drives both:
- `CanvasPreviewRenderer.tsx` (HTML5 Canvas 2D)
- `figma-renderer.ts` (Figma `RectangleNode`, `TextNode`, `createNodeFromSvg`, `GRADIENT_LINEAR`, `blendMode`)

Any change to layout, colors, opacity, or geometry must be made in `src/generator/` and reflected identically in both renderers.
